พื้นฐาน CSS, Box Model และ Layout Positioning

1. พื้นฐาน CSS, การเชื่อมต่อ และ Selector

แนวคิด CSS: CSS ทำหน้าที่เหมือนการ "ตกแต่งภายใน/ภายนอกบ้าน" แยกส่วนกับโครงสร้าง HTML ชัดเจน ช่วยให้แก้ไขสไตล์ของหลายๆ หน้าเว็บได้พร้อมกันในจุดเดียว

รูปแบบการเชื่อมต่อหลัก:
  • Internal (สไตล์ชีตภายใน): เขียนในแท็ก <style> ภายใน <head> เหมาะกับหน้าเว็บขนาดเล็ก หรือ Single Page ไม่สามารถแชร์ไปหน้าอื่นได้
  • External (สไตล์ชีตภายนอก): สร้างไฟล์ .css แยก แล้วใช้แท็ก <link> ใน HTML เพื่อดึงสไตล์มาใช้ (เป็นมาตรฐานระดับมืออาชีพ)
CSS Selectors (การชี้เป้าหมาย):
  • Tag Selector: พิมพ์ชื่อแท็กตรงๆ (เช่น p) ส่งผลต่อแท็กนั้นทุกตัวในหน้า (ระดับความเฉพาะเจาะจงกว้างสุด)
  • Class Selector: ใช้จุดนำหน้า (เช่น .btn) ใช้ซ้ำกี่ครั้งก็ได้ และใช้กับแท็กใดก็ได้ นิยมใช้กับกลุ่มปุ่มหรือการ์ดสินค้า
  • ID Selector: ใช้เครื่องหมายแฮชแท็กนำหน้า (เช่น #navbar) ห้ามใช้ซ้ำในหน้าเดียวกัน (เหมือนเลขบัตรประชาชน) ใช้กับส่วนประกอบหลักที่มีชิ้นเดียว
/* ตัวอย่างการเขียน CSS Selectors */
p { color: #333; } /* Tag Selector */
.btn { background: #087ff5; } /* Class Selector */
#navbar { width: 100%; } /* ID Selector */
2. ระบบกล่อง (Box Model)

บราวเซอร์มองทุกองค์ประกอบบนหน้าเว็บเป็น "กล่องสี่เหลี่ยม" ซ้อนกัน 4 ชั้น (เรียงจากในไปนอก):

  • Content (Width/Height): เนื้อหาหลัก (ข้อความ/รูปภาพ) กำหนดขนาดได้ทั้งพิกเซล (px) หรือเปอร์เซ็นต์ (%)
  • Padding (พื้นที่ใน): ระยะห่างภายในกล่อง (จากเนื้อหาถึงเส้นขอบ) เปรียบเหมือนพลาสติกกันกระแทก ช่วยให้กล่องดูโปร่งสบาย
  • Border (เส้นขอบ): กรอบ/กำแพงกั้นระหว่างพื้นที่ภายในและภายนอก ปรับความหนา สี และสไตล์ได้
  • Margin (พื้นที่นอก): ระยะห่างภายนอกกล่อง เปรียบเหมือน Social Distancing ช่วยผลักกล่องอื่นออกไป ไม่ให้เบียดชิดกัน
3. การจัดตำแหน่ง (Layout Positioning)

ตามปกติบราวเซอร์จะวางองค์ประกอบเรียงจากบนลงล่าง ซ้ายไปขวา (Normal Flow) จึงต้องใช้คำสั่ง CSS จัดระเบียบ:

การใช้ Display (พฤติกรรมกล่อง):
  • Block: จองพื้นที่เต็ม 100% ความกว้างบรรทัดเสมอ (เช่น <div>, <p>) ขึ้นบรรทัดใหม่ทุกครั้ง
  • Inline: ใช้พื้นที่เท่าขนาดเนื้อหา สามารถวางเรียงต่อกันในบรรทัดเดียวได้ (เช่น <span>, <a>) แต่กำหนด Width/Height ไม่ได้
  • Flex (Flexbox): มาตรฐานยุคใหม่ เปลี่ยนกล่องแม่เป็นโครงสร้างยืดหยุ่น จัดเรียง/กระจาย/จัดกึ่งกลางกล่องลูกได้ง่ายดาย
การใช้ Position (การกำหนดพิกัด X, Y):
  • Relative: เคลื่อนย้ายโดยอ้างอิงจาก จุดเดิม ที่เคยอยู่ (ช่องว่างเดิมยังคงถูกเว้นไว้)
  • Absolute: ดึงกล่อง หลุดออกจากวงโคจร นำไปวางแปะทับพิกัดใดก็ได้ของกล่องแม่ (เช่น ป้าย Badge แจ้งเตือน)
  • Fixed: ดึงกล่องออกมา ยึดติดกับหน้าจอ (Viewport) ไม่ว่าจะเลื่อน Scroll ไปไหนก็ไม่หาย นิยมใช้ทำ Sticky Navbar หรือปุ่ม Chat
เทคนิคสำคัญของ Position
หากต้องการใช้งาน position: absolute ให้ได้ผลลัพธ์ที่ถูกต้อง อย่าลืมกำหนด position: relative ที่กล่องแม่ เพื่อขีดขอบเขตอ้างอิงพิกัดเสมอ
