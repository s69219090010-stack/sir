การสร้างและตกแต่งตาราง (HTML Tables & Modern CSS)

1. โครงสร้างพื้นฐานของตาราง HTML (Table Blueprint)
  • <table>: แท็กสำหรับกำหนดขอบเขตทั้งหมดของตาราง เปรียบเสมือนโครงตู้หรือชั้นวางของ
  • <tr> (Table Row): ใช้สำหรับสร้าง "แถวในแนวนอน" ของตาราง ข้อมูลตารางทั้งหมดต้องจัดวางภายในแถว <tr>
  • <th> (Table Header): เซลล์หัวข้อตาราง ข้อความภายในจะเป็นตัวหนาและจัดกึ่งกลางโดยอัตโนมัติ ช่วยสร้าง Semantic HTML และความชัดเจนของข้อมูล
  • <td> (Table Data): เซลล์ข้อมูลทั่วไปภายในตาราง ข้อความจะชิดซ้ายโดยอัตโนมัติ
<!-- โครงสร้างพื้นฐานของ HTML Table -->
<table>
  <tr>
    <th>หัวข้อ 1</th>
    <th>หัวข้อ 2</th>
  </tr>
  <tr>
    <td>ข้อมูล 1</td>
    <td>ข้อมูล 2</td>
  </tr>
</table>
2. การควบรวมเซลล์และการจัดโครงสร้างระดับสูง (Advanced HTML Cell)
  • colspan (Column Span): ใช้สำหรับ "รวมเซลล์ในแนวนอน" (ผสานคอลัมน์) เช่น colspan="2" คือการรวม 2 คอลัมน์เข้าด้วยกัน
  • rowspan (Row Span): ใช้สำหรับ "รวมเซลล์ในแนวตั้ง" (ผสานแถว) เช่น rowspan="2" คือการรวม 2 แถวเข้าด้วยกัน
โครงสร้างแบ่งส่วนตาราง (Table Semantic Structure):
  • <thead>: ส่วนหัวของตาราง (เก็บ <th>)
  • <tbody>: ส่วนเนื้อหาหลักของตาราง (เก็บ <td>)
  • <tfoot>: ส่วนสรุปท้ายตาราง (เช่น ผลรวม หรือจำนวนทั้งหมด)
3. การตกแต่งตารางด้วย CSS สมัยใหม่ (Modern CSS Table Styling)
  • border-collapse: collapse;: รวมเส้นขอบของเซลล์ตารางที่ซ้อนกันให้เหลือเพียงเส้นเดียว ช่วยให้ตารางดูคมชัด ไม่เป็นเส้นคู่หนาๆ
  • การจัดระยะห่าง (Padding): เพิ่มระยะห่างภายในเซลล์ด้วย CSS padding เพื่อไม่ให้ตัวอักษรเบียดชิดเส้นขอบตาราง
  • Zebra Striping (ตารางสลับสี): ใช้ CSS Pseudo-class :nth-child(even) หรือ :nth-child(odd) ในการใส่สีพื้นหลังสลับแถว ช่วยให้ผู้ใช้งานกวาดสายตาอ่านข้อมูลจำนวนมากได้ง่ายขึ้น
  • Hover Effect: ใช้ tr:hover เพื่อเปลี่ยนสีพื้นหลังของแถวเมื่อนำเมาส์ไปวาง ช่วยเพิ่มการโต้ตอบ (Interactive) และประสบการณ์ผู้ใช้ที่ดี (UX)
/* ตัวอย่างการตกแต่งตารางด้วย CSS */
table { width: 100%; border-collapse: collapse; }
th, td { padding: 12px; border: 1px solid #ddd; }
tbody tr:nth-child(even) { background-color: #f9f9f9; } /* Zebra Striping */
tbody tr:hover { background-color: #f1f1f1; } /* Hover Effect */
4. ตารางแบบยืดหยุ่นและการจัดวาง (Responsive Tables)

Overflow Handling: ห่อหุ้มตารางไว้ใน <div class="table-responsive"> แล้วใช้ CSS overflow-x: auto; เพื่อให้ตารางบนหน้าจอขนาดเล็ก (สมาร์ตโฟน) สามารถเลื่อนขวา-ซ้าย (Horizontal Scroll) ได้ โดยไม่ทำให้เลย์เอาต์หลักของหน้าเว็บเบี้ยวหรือล้นจอ

ข้อควรระวังการทำ Responsive Table
การใส่ overflow-x: auto; ต้องกำหนดไว้ที่ <div> กล่องแม่ ที่ครอบตารางไว้เสมอ ไม่ควรกำหนดที่ตัวแท็ก <table> โดยตรง
