บทที่ 8

การสร้างฟอร์มและการรับข้อมูล (HTML Forms & Validation)

1. องค์ประกอบและโครงสร้างของฟอร์ม (<form>)
  • แท็ก <form>: ใช้เป็นกล่องครอบองค์ประกอบรับข้อมูลทั้งหมดเพื่อส่งไปยังเซิร์ฟเวอร์
  • แอตทริบิวต์ action: ระบุ URL หรือไฟล์ปลายทาง (เช่น เซิร์ฟเวอร์/สคริปต์) ที่จะรับข้อมูลไปประมวลผล
  • แอตทริบิวต์ method (การส่งข้อมูล):
    • GET: ส่งข้อมูลผ่าน URL ต่อท้ายด้วยข้อความ (Query String) เหมาะกับการค้นหาทั่วไป แต่ไม่ปลอดภัย และมีข้อจำกัดเรื่องขนาดข้อมูล
    • POST: แนบข้อมูลไปกับ Body ของ HTTP Request เหมาะกับการส่งข้อมูลสำคัญ (เช่น รหัสผ่าน) หรือข้อมูลที่มีขนาดใหญ่ เพราะมีความปลอดภัยมากกว่า
<!-- ตัวอย่างโครงสร้างการประกาศฟอร์ม -->
<form action="process.php" method="POST">
  <!-- ช่องรับข้อมูลต่างๆ อยู่ที่นี่ -->
</form>
2. ประเภทของช่องรับข้อมูล (Input Types)
กลุ่มรับข้อมูลข้อความ (Text Inputs):
  • type="text": ช่องกรอกข้อความทั่วไปแบบบรรทัดเดียว
  • type="password": ช่องกรอกรหัสผ่าน (ซ่อนข้อความด้วยจุดหรือดอกจัน)
  • <textarea>: ช่องกรอกข้อความขนาดยาวแบบหลายบรรทัด (เช่น ข้อเสนอแนะ หรือที่อยู่)
กลุ่มตัวเลือก (Selection Controls):
  • type="radio": ตัวเลือกแบบเลือกได้เพียง 1 อย่าง ในกลุ่มเดียวกัน (ต้องใช้ name เดียวกัน)
  • type="checkbox": ตัวเลือกที่สามารถ เลือกหลายรายการ หรือไม่เลือกเลยก็ได้
  • <select> และ <option>: เมนูรายการแบบดรอปดาวน์ (Dropdown List)
3. การตรวจสอบความถูกต้องของข้อมูล (Form Validation)

ใช้แอตทริบิวต์ของ HTML5 ในการควบคุมและตรวจสอบข้อมูลฝั่งเบราว์เซอร์ก่อนส่งไปยังเซิร์ฟเวอร์:

  • required: บังคับว่าต้องกรอกข้อมูล หากไม่กรอกจะไม่สามารถกดส่งฟอร์มได้
  • min / max: กำหนดค่าต่ำสุดและสูงสุดสำหรับช่องข้อมูลที่เป็นตัวเลขหรือวันที่
  • minlength / maxlength: กำหนดจำนวนตัวอักษรขั้นต่ำและสูงสุดที่ยอมให้กรอก
  • pattern: ใช้ Regular Expression (RegEx) กำหนดรูปแบบข้อมูลที่ถูกต้อง (เช่น รูปแบบเบอร์โทรศัพท์ หรือรหัสไปรษณีย์)
<!-- ตัวอย่างการใช้ HTML5 Form Validation -->
<input type="text" name="username" required minlength="4" maxlength="20">
<input type="text" name="phone" pattern="[0-9]{10}" placeholder="กรอกเบอร์โทร 10 หลัก">
4. การป้อนและส่งข้อมูล (Buttons & UX Enhancements)
  • <label> และแอตทริบิวต์ for: ผูกข้อความอธิบายเข้ากับช่องรับข้อมูล (id) เพื่อให้ผู้ใช้สามารถคลิกที่ข้อความแล้ว Cursor ไปโฟกัสที่ช่องกรอกได้ทันที เพิ่ม UX ให้ใช้งานง่ายขึ้น
  • ปุ่มกด (Buttons):
    • type="submit": ปุ่มส่งข้อมูลในฟอร์มไปยังปลายทาง
    • type="reset": ปุ่มล้างข้อมูลทั้งหมดในฟอร์มกลับเป็นค่าเริ่มต้น
เทคนิคเพิ่ม UX สำหรับ Label
การจับคู่ <label for="user-email"> ต้องตรงกับ id="user-email" ของช่องรับข้อมูลเสมอ เพื่อให้คลิกที่ข้อความแล้วเมาส์ไปโฟกัสในช่องกรอกได้ทันที
