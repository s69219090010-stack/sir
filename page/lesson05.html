บทที่ 5

การจัดการข้อความ รูปภาพ มัลติมีเดีย และ Iframe

1. การจัดการข้อความระดับสูง (Advanced Text Styling)

เป้าหมาย: สร้าง Visual Hierarchy (ลำดับสายตา) และสื่อสารตัวตนของแบรนด์

การปรับแต่งด้วย CSS:
  • Color: กำหนดสีตัวอักษรได้ทั้งชื่อสี, รหัส Hex Code (#FF5733) หรือ RGB เพื่อให้ได้เฉดสีตรงตามต้องการ
  • Font-size: ควบคุมขนาดข้อความ โดยนิยมใช้หน่วยพิกเซล (px) สำหรับผู้เริ่มต้น (เนื้อหาทั่วไปไม่ควรต่ำกว่า 16px)
Google Fonts (Cloud Font Service):

แก้ปัญหาฟอนต์ไม่แสดงผลในเครื่องผู้ใช้ด้วยการดึงฟอนต์จากคลาวด์ของ Google มาแสดงผลแบบ Real-time โดยการเชื่อมต่อไฟล์ HTML ผ่านแท็ก <link> ในส่วน <head> แล้วใช้คำสั่ง font-family ใน CSS เพื่อเรียกชื่อฟอนต์

<!-- ตัวอย่างการเชื่อมต่อ Google Fonts ใน <head> -->
<link href="https://fonts.googleapis.com/css2?family=Sarabun&display=swap" rel="stylesheet">

/* ตัวอย่างการเรียกใช้งานใน CSS */
body { font-family: 'Sarabun', sans-serif; font-size: 16px; color: #333333; }
2. การแทรกและจัดการรูปภาพ (<img>)

ลักษณะของแท็ก <img>: เป็นแท็กเดี่ยว (Empty Tag) ที่ใช้การ "ชี้เป้าหมาย" ผ่านแอตทริบิวต์ src (Source)

การระบุที่อยู่ไฟล์ (Path):
  • Absolute Path: อ้างอิง URL เต็มรูปแบบจากเว็บอื่น (ขึ้นต้นด้วย http:// หรือ https://) ข้อเสียคือถ้ารูปต้นทางถูกลบ รูปจะหายทันที
  • Relative Path: อ้างอิงจากตำแหน่งโฟลเดอร์ในโปรเจกต์ของตัวเอง (เช่น images/coffee.jpg) เป็นมาตรฐานที่ควรใช้
Image Optimization (ประสิทธิภาพเว็บ)
ต้องบีบอัดและย่อขนาดภาพก่อนใช้งานจริงเสมอ เพื่อป้องกันเว็บโหลดช้า และหลีกเลี่ยงผลกระทบต่อคะแนน SEO รวมถึงเลือกใช้ประเภทไฟล์ให้เหมาะสม เช่น .jpg (ภาพถ่าย), .png (พื้นหลังโปร่งใส) หรือ .webp (ขนาดเล็กพิเศษ)
3. การจัดการวิดีโอและเสียง (<video> & <audio>)

มาตรฐาน HTML5: สามารถเล่นสื่อมัลติมีเดียได้ในตัวโดยไม่ต้องพึ่งพิงโปรแกรมเสริม (Plugin) อย่าง Flash Player ในอดีต

  • แท็ก <video>: ใช้ระบุไฟล์วิดีโอผ่านแอตทริบิวต์ src
  • แอตทริบิวต์ controls: เป็นส่วนสำคัญที่สุดในการเสก "แผงควบคุม" (ปุ่ม Play/Pause, ปรับเสียง, Timeline, ขยายเต็มจอ) เพื่อให้ผู้ใช้งานโต้ตอบได้
<!-- ตัวอย่างการใช้งานแท็ก Video ใน HTML5 -->
<video src="videos/presentation.mp4" controls width="100%"></video>
4. การใช้ Inline Frame (<iframe>)

หลักการทำงาน: ทำหน้าที่เหมือนการ "เจาะหน้าต่างกระจก" บนหน้าเว็บ เพื่อดึงเนื้อหาหรือบริการจากเว็บไซต์ภายนอก (Third-party) มาแสดงผล

แอตทริบิวต์สำคัญ: src (URL ปลายทาง), width/height (ขนาดหน้าต่าง), title (คำอธิบายสำหรับ Screen Reader) และ allowfullscreen

การประยุกต์ใช้งานจริง (Embed Services):

นิยมใช้ฝังบริการระดับโลกเพื่อประหยัดพื้นที่เซิร์ฟเวอร์ของตัวเอง เช่น:

  • YouTube Embed: ฝังคลิปวิดีโอพร้อมแผงควบคุมโดยไม่ต้องอัปโหลดไฟล์วิดีโอขนาดใหญ่ลงเซิร์ฟเวอร์
  • Google Maps Embed: ฝังแผนที่ Interactive ให้ผู้ใช้สามารถซูม เลื่อน หรือเลิอกระบบนำทาง GPS ได้ทันที
