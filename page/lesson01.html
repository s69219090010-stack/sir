บทที่ 1

พื้นฐานการพัฒนาเว็บไซต์

1. สถาปัตยกรรมและการทำงานของเว็บไซต์ (Web Infrastructure)

แนวคิด Client-Server: เว็บไซต์ทำงานผ่านการสื่อสารระหว่าง Client (เครื่องผู้ใช้/เว็บบราวเซอร์) ที่ส่งคำขอ (Request) ไปยัง Server (เครื่องแม่ข่าย) เพื่อประมวลผลและส่งข้อมูล (Response) กลับมาแสดงผล

  • HTTP / HTTPS: มาตรฐานการสื่อสารข้อมูล โดย HTTPS เพิ่มระบบความปลอดภัยและการเข้ารหัสข้อมูล (Security)
  • IP Address & Domain Name: IP Address คือหมายเลขประจำเครื่องในระบบเครือข่าย ส่วน Domain Name (เช่น google.com) คือชื่อที่ใช้เรียกแทน IP Address เพื่อให้มนุษย์จดจำได้ง่าย
// ตัวอย่างกระบวนการ Request / Response
Client Request -> https://www.example.com
Server Response -> 200 OK (HTML/CSS/JS Data)
2. การวางโครงสร้างและประสบการณ์ผู้ใช้ (Web Architecture & UX)

Site Map & Navigation Flow: การจัดวางผังหน้าเว็บไซต์และเส้นทางการเชื่อมโยงระหว่างหน้าต่างๆ เพื่อให้ผู้ใช้ไม่งง

ข้อควรจำ
กฎ 3 คลิก (3-Click Rule): หลักการออกแบบที่ช่วยให้ผู้ใช้งานสามารถเข้าถึงข้อมูลที่ต้องการได้ภายในไม่เกิน 3 การคลิกจากหน้าแรก
3. การจัดเตรียมเครื่องมือพัฒนาโปรแกรม (Development Environment Setup)

Visual Studio Code (VS Code): โปรแกรม Code Editor หลักที่ใช้ในการเขียนโค้ดเว็บไซต์

ส่วนขยายแนะนำ (VS Code Extensions):
  1. Live View / Server: ช่วยจำลองการแสดงผลหน้าเว็บแบบเรียลไทม์ขณะแก้ไขโค้ด
  2. Formatting & Syntax Check: ช่วยจัดระเบียบโครงสร้างโค้ดและตรวจสอบข้อผิดพลาด
  3. HTML Tag Automation: ช่วยเติมแท็กอัตโนมัติเพื่อเพิ่มความเร็วในการเขียนโค้ด
