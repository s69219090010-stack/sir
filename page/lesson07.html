ระบบการเชื่อมโยง (Hyperlinks)

1. พื้นฐานและการใช้งานลิงก์ (<a> Tag & href Attribute)
  • แท็ก <a> (Anchor Tag): ใช้สำหรับสร้างไฮเปอร์ลิงก์เพื่อเชื่อมโยงเอกสารเว็บเพจเข้าด้วยกัน
  • แอตทริบิวต์ href (Hypertext Reference): เป็นหัวใจสำคัญที่ใช้ระบุ URL หรือเส้นทางปลายทางที่ต้องการให้ลิงก์พาผู้ใช้ไป
<!-- โครงสร้างพื้นฐานการใช้งานแท็ก Anchor -->
<a href="https://www.example.com">ข้อความลิงก์</a>
2. การอ้างอิงที่อยู่ไฟล์ (Path Types)
  • Relative Path (เส้นทางสัมพัทธ์): ใช้สำหรับเชื่อมโยงไฟล์ภายในเว็บไซต์เดียวกัน (Internal Link) โดยอ้างอิงจากตำแหน่งของไฟล์ปัจจุบัน เช่น href="about.html" หรือ href="pages/contact.html"
  • Absolute Path (เส้นทางสัมบูรณ์): ใช้สำหรับเชื่อมโยงไปยังเว็บไซต์ภายนอก (External Link) โดยระบุ URL แบบเต็มรูปแบบ เช่น href="https://www.google.com"
3. การควบคุมพฤติกรรมการเปิดลิงก์และ Anchor Link
  • แอตทริบิวต์ target="_blank": บังคับให้เบราว์เซอร์เปิดลิงก์ปลายทางใน แท็บใหม่หรือหน้าต่างใหม่ นิยมใช้กับลิงก์ภายนอก เพื่อไม่ให้ผู้ใช้งานหลุดออกจากหน้าเว็บไซต์เดิม
  • Anchor Link (การเลื่อนตำแหน่งภายในหน้าเพจ): ใช้เชื่อมโยงไปยังส่วนต่างๆ ของหน้าเพจเดียวกันผ่านการระบุ id เช่น href="#section2" เหมาะสำหรับหน้าเพจที่มีเนื้อหายาวมากๆ เพื่อช่วยข้ามไปยังส่วนที่ต้องการได้ทันที
<!-- เปิดในแท็บใหม่ -->
<a href="https://www.google.com" target="_blank">ไปยัง Google</a>

<!-- ลิงก์ข้ามไปยังตำแหน่ง ID ภายในหน้าเดียวกัน -->
<a href="#section2">ไปยังส่วนที่ 2</a>
4. การตกแต่งและสถานะของลิงก์ด้วย CSS (Pseudo-classes)

จัดการสถานะและวงจรชีวิตของลิงก์เพื่อเพิ่มการตอบสนอง (Interactive) และ UX ที่ดี:

  • :link: สไตล์ของลิงก์สถานะปกติที่ยังไม่เคยถูกคลิก
  • :visited: สไตล์ของลิงก์ที่ผู้ใช้งานเคยคลิกเข้าไปแล้ว
  • :hover: สไตล์เมื่อผู้ใช้นำเมาส์ไปวางเหนือลิงก์ (เช่น การเปลี่ยนสี หรือขีดเส้นใต้)
  • :active: สไตล์ในขณะที่ผู้ใช้กำลังกดคลิกลิงก์อยู่
  • การประยุกต์ทำปุ่มกด (Button): ใช้ CSS เปลี่ยนข้อความลิงก์ธรรมดาให้กลายเป็น "ปุ่มกด (Button)" ที่สวยงาม สื่อสารการใช้งานได้ชัดเจนขึ้น
ลำดับการเขียน CSS Pseudo-classes (LVHA)
การเรียงลำดับ CSS Pseudo-classes ของลิงก์มีผลต่อการแสดงผล แนะนำให้จำกฎ LVHA: :link → :visited → :hover → :active เสมอ
