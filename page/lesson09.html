พื้นฐานภาษา JavaScript และ DOM Manipulation

1. บทบาทและพื้นฐานของภาษา JavaScript
  • ภาษา JavaScript: ทำหน้าที่สร้างการโต้ตอบ (Interactivity) และไดนามิกให้กับหน้าเว็บ (เปรียบเสมือนระบบประสาทและกล้ามเนื้อที่ทำให้บ้านเคลื่อนไหวได้)
  • ตำแหน่งการเขียนโค้ด:
    • Internal JS: เขียนภายในแท็ก <script> ในไฟล์ HTML
    • External JS: แยกไฟล์เป็น .js แล้วเชื่อมโยงผ่าน <script src="script.js"></script>
  • การแสดงผลขั้นพื้นฐาน: ใช้คำสั่ง console.log() เพื่อตรวจสอบสถานะการทำงาน และ alert() เพื่อแสดงกล่องข้อความแจ้งเตือนผู้ใช้
// ตัวอย่างการใช้งาน External JS และคำสั่งแสดงผล
console.log("Hello, JavaScript!");
alert("ยินดีต้อนรับสู่บทเรียน JavaScript");
2. ตัวแปร ชนิดข้อมูล และตัวดำเนินการ (Variables & Data Types)
การประกาศตัวแปร:
  • let: ใช้ประกาศตัวแปรที่ สามารถเปลี่ยนค่าได้ ในภายหลัง
  • const: ใช้ประกาศค่าคงที่ ห้ามเปลี่ยนค่า (แนะนำให้ใช้เป็นค่าเริ่มต้นหากไม่มีการแก้ไขค่า)
  • var: รูปแบบเก่า (ไม่นิยมใช้ในปัจจุบันเนื่องจากปัญหา Scope)
  • ชนิดข้อมูลพื้นฐาน (Data Types): ข้อความ (String), ตัวเลข (Number), ค่าความจริง (Boolean: true/false), ค่าว่าง (null, undefined)
  • ตัวดำเนินการ (Operators): เครื่องมือคำนวณทางคณิตศาสตร์ (+, -, *, /) และการเปรียบเทียบค่า (===, !==, >, <)
3. การควบคุมทิศทางและฟังก์ชัน (Control Flow & Functions)
  • เงื่อนไข (If-Else Statement): ใช้ตัดสินใจเลือกทำงานตามเงื่อนไข เช่น ตรวจสอบว่าผู้ใช้อายุเกิน 18 ปีหรือไม่ หรือตรวจสอบรหัสผ่าน
  • การวนซ้ำ (Loops): ใช้สั่งให้เบราว์เซอร์ทำงานซ้ำๆ (เช่น for loop หรือ while loop) สำหรับการประมวลผลข้อมูลจำนวนมาก
  • ฟังก์ชัน (Functions): การรวมชุดคำสั่งเข้าด้วยกันเพื่อให้นำกลับมาใช้ซ้ำได้ (Reusable Code) ประกาศด้วยคีย์เวิร์ด function และคืนค่าผลลัพธ์ผ่านคำสั่ง return
// ตัวอย่างการประกาศและการสร้างฟังก์ชัน
function checkAge(age) {
  if (age >= 18) {
    return "ผ่านการตรวจสอบ";
  } else {
    return "อายุไม่ถึงเกณฑ์";
  }
}
4. DOM Manipulation และ Event Handling
  • DOM (Document Object Model): โครงสร้างที่ JavaScript มององค์ประกอบ HTML บนหน้าเว็บเป็น Object
  • การเข้าถึงและแก้ไข HTML: ใช้คำสั่ง เช่น document.getElementById() หรือ document.querySelector() เพื่อเข้าถึง และแก้ไขเนื้อหาผ่าน .innerText, .innerHTML หรือปรับสไตล์ CSS ผ่าน .style
  • การดักจับเหตุการณ์ (Event Handling): ตอบสนองต่อการกระทำของผู้ใช้ เช่น การกดปุ่ม (click), การพิมพ์ (input), หรือการเลื่อนเมาส์ (mouseover) ผ่านคำสั่ง addEventListener() เพื่อทำให้หน้าเว็บทำงานแบบ Interactive
เทคนิคสำคัญของ Event Handling
การใช้ addEventListener("click", function) ช่วยแยกการทำงานของ JavaScript ออกจาก HTML ได้อย่างเป็นระเบียบ ทำให้จัดการโค้ดในโปรเจกต์ขนาดใหญ่ได้ง่ายขึ้น
