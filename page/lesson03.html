พื้นฐานภาษา HTML5 และการจัดการแท็ก (HTML5 Fundamentals & Tags)

1. พื้นฐานและโครงสร้างไฟล์มาตรฐาน (HTML5 Basics & Structure)

HTML5: ทำหน้าที่เป็นเสาเข็ม/โครงสร้างหลักของเว็บไซต์ (เปรียบเหมือนโครงสร้างบ้าน) เวอร์ชันปัจจุบันรองรับมัลติมีเดีย (Video/Audio) โดยไม่ต้องใช้ Plugin และสนับสนุน Semantic Tags ซึ่งส่งผลดีต่อ SEO และ Screen Reader (Accessibility)

โครงสร้างมาตรฐาน 3 ส่วนหลัก:
  • <!DOCTYPE html> & <html>: ประกาศใช้มาตรฐาน HTML5 ไว้บรรทัดแรกสุด และใช้ <html> ล้อมรั้วขอบเขตเว็บทั้งหมด (ระบุภาษาหลักได้ เช่น <html lang="th">)
  • <head>: ส่วนควบคุมหลังบ้าน เก็บข้อมูลเชิงเทคนิคที่ไม่แสดงผลบนหน้าจอ เช่น การเชื่อมโยงไฟล์ CSS และมีแท็ก <title> สำหรับแสดงชื่อหน้าเว็บบนแท็บบราวเซอร์และหน้า Search Engine
  • <body>: พื้นที่ใช้สอยหลัก แสดงผลข้อมูลทั้งหมดให้ผู้ใช้งานมองเห็น (ข้อความ รูปภาพ ปุ่มกด ฯลฯ)
<!-- โครงสร้างพื้นฐานของ HTML5 -->
<!DOCTYPE html>
<html lang="th">
  <head>
    <title>ชื่อหน้าเว็บ</title>
  </head>
  <body>
    <h1>Hello World</h1>
  </body>
</html>
2. การจัดการข้อความด้วย Tag และ Attribute

Heading Tags (<h1> ถึง <h6>): แท็กพาดหัวข่าว จัดลำดับความสำคัญของเนื้อหา โดย <h1> ใหญ่และสำคัญที่สุด (ควรมีเพียง 1 ตัวต่อหน้าเพจ เพื่อผลดีต่อ SEO) ลดหลั่นไปจนถึง <h6>

ย่อหน้าและการขึ้นบรรทัดใหม่:
  • <p> (Paragraph): ใช้จัดกลุ่มข้อความย่อหน้า บราวเซอร์จะเว้นระยะห่าง (Margin) บน-ล่างให้อัตโนมัติ
  • <br> (Line Break): แท็กบังคับขึ้นบรรทัดใหม่ทันที (เนื่องจากการกด Enter บนแป้นพิมพ์ บราวเซอร์จะนับเป็นช่องว่างเพียง 1 ช่อง)
3. การสร้างรายการข้อมูล (Lists)

จัดกลุ่มข้อมูลให้เป็นหมวดหมู่ อ่านง่าย และช่วยจัดโครงสร้าง Semantic HTML ให้ SEO/Screen Reader:

  • Unordered List (<ul>): รายการแบบไม่มีลำดับ (ไม่เน้นก่อน-หลัง) ใช้จุด Bullet (<li>) นำหน้า
  • Ordered List (<ol>): รายการแบบมีลำดับ (ขั้นตอนสลับไม่ได้) บราวเซอร์จะรันตัวเลขให้อัตโนมัติ ปรับแต่งได้ด้วย Attribute:
    • type: กำหนดรูปแบบตัวเลข/ตัวอักษร (เช่น A, a, I, 1)
    • start: กำหนดตัวเลขเริ่มต้น (เช่น start="5")
    • reversed: แสดงตัวเลขเรียงนับถอยหลัง
  • Nested Lists: การสร้างรายการซ้อนกันในหมวดหมู่ย่อย (กฎสำคัญ: รายการย่อยต้องอยู่ภายในแท็ก <li> ของรายการหลักเสมอ)
4. ส่วนขยาย (Extensions) ใน VS Code และ Local Server

ช่วยเพิ่มประสิทธิภาพในการพัฒนาและลดข้อผิดพลาด:

  • Code Formatting & Syntax:
    - Prettier: จัดรูปแบบและเว้นวรรคโค้ดให้อัตโนมัติเมื่อบันทึกไฟล์
    - Error Lens: แสดงข้อความแจ้งเตือนจุดที่พิมพ์โค้ดผิดพลาดที่ท้ายบรรทัดทันที
  • HTML Tag Automation:
    - Auto Rename Tag: เปลี่ยนชื่อแท็กปิดให้อัตโนมัติเมื่อแก้ไขแท็กเปิด
    - Auto Close Tag: เติมแท็กปิดให้อัตโนมัติ
  • Live Server: ช่วยจำลองสภาพแวดล้อม Local Server (HTTP Protocol: http://localhost) เหมือนการรันบนอินเทอร์เน็ตจริง ซึ่งแม่นยำกว่าการเปิดไฟล์ตรงๆ (File Protocol: file:///)
ข้อสังเกตการติดตั้งส่วนขยาย
ควรเลือกติดตั้งส่วนขยายที่มี Verified Publisher (เครื่องหมายติ๊กถูก) และมียอดดาวน์โหลดสูงเพื่อความปลอดภัยและเสถียรภาพในการใช้งาน
